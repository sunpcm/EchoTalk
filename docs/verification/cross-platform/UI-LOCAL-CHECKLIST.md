# 本地布局验收清单

供 Web/iOS/macOS 共享页面的布局任务选择使用；只证明实际运行的浏览器、视口与文字缩放场景，不能代替原生真机或真实服务验收。

- 固定浏览器、视口、文字缩放、locale和内容夹具；至少选本次受影响的窄屏、长文本及放大场景。
- document宽度不溢出只证明全页边界；另检查标题、按钮等关键元素的clientWidth/scrollWidth及内容框，防止内部裁切或逐字竖排。
- 判断文字与控件重叠时，用Range测真实文字范围；全宽block的矩形相交不自动等于文字重叠。多行文本需要检查各行范围。
- 查看关键截图，确认可读性、换行和点击区域；机器几何通过不能替代视觉核验。失败截图、修正探针及最终截图分别保留。
- 先确认探针是否实际覆盖目标（包括已捕获旧回调的真实执行），再判产品缺陷；有价值的稳定回归进入默认测试。

检查与变异、源码修改串行；恢复后复核字节和指纹，再做最终验收。只报告已运行范围，不把测试数量当完整覆盖。
