## A2 平台/环境构建与iOS同步隔离（2026-10-21）

基线 `409b73548fe1a65a88b05cce0109a04404dbef4b`，分支 `codex/cp01-build-isolation`。
遵守 `docs/CROSS_PLATFORM_ARCHITECTURE.md` §8.2 契约：

1. 产物目录与隔离：
   - 旧 `pnpm build` 默认产物保持 `dist` 兼容；
   - 新增显式平台构建 `build:web` 与 `build:ios`，产物独立输出至 `dist/<platform>/<mode>`（支持 `development`/`staging`/`production`）；
   - 严禁清空或遍历整个 `dist` 目录，构建特定平台与模式时仅操作其对应的目标子目录；
   - 构建开始前清理目标目录旧标识，确保构建失败时绝不留下可被 sync 接纳的旧 success 标识；
   - 成功构建后生成不含任何 Token/密钥的 `build-manifest.json`，仅记录 `platform`、`mode`、`apiOrigin`、`authMode`、`builtAt` 与 `success`。

2. 环境配置静态校验：
   - 统一由 app 目录加载 Vite 环境配置 (`loadEnv(mode, appDir, "VITE_")`) 并允许 `process.env` 覆盖，禁止读取根目录 `.env`；
   - iOS 平台的 `production` 与 `staging` 模式强制要求有效 HTTPS API 地址与 OIDC 模式 (`VITE_AUTH_MODE=oidc`)，且必须具备完整 HTTPS authority、client_id 与 redirect_uri；
   - 拒绝 `VITE_DEV_AUTH_TOKEN` 与 dev 认证，且校验错误信息绝不回显敏感 Token 值；
   - 严禁在 `production` 构建中使用 `--mode development` 旁路；
   - `development` 模式明确允许本机 HTTP 开发配置与 devToken。

3. Capacitor 与 iOS 同步隔离：
   - `capacitor.config.ts` 动态映射 `webDir`：指定 `ECHOTALK_BUILD_PLATFORM=ios` 与 `ECHOTALK_BUILD_MODE` 时映射至对应 `dist/ios/<mode>`，未指定时默认回退 `dist` 兼容历史流程；
   - `sync:ios` 显式限定 iOS 目标，在调用 `cap sync ios` 前严格验证目标目录存在性、`index.html` 存在性及 manifest 标识（平台必须为 `ios`、模式严格匹配、`success: true`）；
   - 缺少产物、缺少 manifest、损坏 manifest 或传入 Web 产物时坚决拒绝并退出非零码，严禁静默回退默认旧 `dist`；
   - 子进程 `spawn` 参数数组且 `shell: false`，非零退出码严格向上传播；
   - Capacitor sync 退出 0 后进一步逐一核验原生公共目录 (`ios/App/App/public`) 与源产物目录 (`dist/ios/<mode>`) 的全部常规文件一致性（包括 `index.html`、`build-manifest.json` 与全部 assets 的存在性与内容字节一致），防止 Capacitor 捕获复制错误后仍退出 0 的静默失败。

4. Turbo 缓存控制：
   - `turbo.json` 显式声明 `env: ["VITE_*", "ECHOTALK_BUILD_*"]`，`inputs` 覆盖脚本与构建配置，`outputs` 完整覆盖默认 `dist/**` 与各平台子目录；
   - 根 `turbo.json` 声明 `globalDependencies: ["packages/configs/**"]`，确保共享 PostCSS (`@biu/postcss-config`) 与 Tailwind (`@biu/tailwind-config`) 配置内容变更必然改变 `vite-app#build:ios` 真实 Turbo 任务哈希；
   - 针对不同 API 变量、平台和模式的 dry-run/哈希特征敏感性经自动化测试验证。

5. 测试与门禁：
   - 新增 `node --test` 回归套件 (`apps/vite-app/scripts/build-isolation-test.mjs`)，覆盖配置合法/非法/缺项校验、敏感字段保护、旁路阻断、目录隔离清理、产物完整性、跨平台/跨模式拒绝、manifest 校验、子进程失败传播、Turbo 哈希敏感性（环境变量、本地 PostCSS 与共享 configs/\*\*）以及 Capacitor 同步后的三种复制状态核验（未复制/错内容/完整复制）共 18 项用例全数通过；
   - 真实新构建/sync 及原生 Xcode 编译由架构评审集中串行核验。未 push、未部署。
