## 4. 周报指标口径（已确认 / 剩余建议）

### 4.1 已确认并实现（不改）

最近七自然日 completed 会话次数、按日只读历史、语法 Top3（rolling7 + `started_at` 归属；0 转录 completed 计 1），以及 opt-in 的“已记录会话时长”。后者的名称已确认，只表示 `ended_at - started_at` 的会话经过时长，不等于有效说话时长；0 转录/未进房不单独区分，跨日仍按 `started_at`，负值/缺失按异常处理。

### 4.2 尚未确认的未来口径

- **掌握度环比（建议「同技能百分点变化」）**：`p_mastery` 是概率，用百分点差而非百分比增长率；同版本（`bkt-v1`）+ 真实来源（`is_synthetic=false`）+ 缺值不入 + 可比基线写清；不能用 `recorded_at` 当提交时间、不承诺过两周必有有效历史。B2 事件不足以自动定义自然周末快照，趋势快照/补处理/完整性仍需设计。
- **发音趋势 / 焦虑 / 语速 / 下周重点**：逐项列出所需输入（当前无法承诺可算）：
  - 发音趋势：需真实发音评估结果（当前 `demo_mock`），无真实输入前不可算。
  - 焦虑/语速：需语音声学或时长切片（当前无持久化用户说话区间，`timestamp_ms` 非音频分段）。
  - 下周重点：依赖掌握度环比与真实评估，需先有可比历史。
- 未来完整自然周与现有 rolling7 不相互覆盖（两者并存，不覆盖既有口径）。

### 4.3 仍需用户确认

掌握度环比是否采用百分点变化；发音趋势/焦虑/语速/下周重点暂不承诺、先补输入。周时长名称“已记录会话时长”已确认，不再重复询问。
