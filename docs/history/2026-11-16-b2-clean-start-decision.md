# B2 开发期干净起步决策记录

> 日期：2026-11-16。范围：学习事件与知识状态的开发期起步决策。本文不包含实施、测试或迁移结果。

用户确认 B2 开发期采用干净起步：旧测试数据、旧分析 Job 和旧资料可丢弃，新事件链从 `p_init=.1`
开始；不保留旧知识状态基线，不承接旧测试 Job，也不回填历史。必要的课程与技能种子和既有结构保留。
1–3 只决定开发数据，正式用户的保留、删除、导出与匿名化政策上线前另定，不能写成已批准账户存续期
保留方案 A。

B2 本阶段不开放重新分析。当前四参数与数值更新语义冻结为 `bkt-v1`：答对先算 posterior 再 transit，
答错返回 posterior，不执行 transit；版本或数值语义变化须新增版本并保留旧事实。Job 并发调度不属于
本次版本冻结，用户锁与确定性观察顺序仍须在实施中验证。会话经过时长只是辅助指标，不能称为有效练习；
掌握度环比使用同技能 `p_mastery` 的百分点差，只接受真实、同版本和可比快照。阶段 C 仅获授权先出
资源费用方案，费用、账号接入和环境创建尚未获准。

原 B1 设计的时点基线和旧 Job 切换后处理仍作为未来真实数据场景的备选保留，其他事件结构、来源归属、
幂等、同事务和重算契约也继续有效。旧候选分支与集成现场只作审计资料，不自动成为当前实现；具体事实
和分包见 [B2 实施计划](../B2_IMPLEMENTATION_PLAN.md)。

本轮只修改决策和实施文档，产品源码、测试和迁移文件未修改；源码仅用于只读核验。旧测试数据的
实际清理、迁移、部署和环境创建均未执行。Harness 在 macOS 亲跑本轮基线三树：Vite Vitest
1270 passed/57 files，命令 21.37s；backend pytest 1068 passed/3 warnings/81.00%，pytest 92.82s、
命令 107.47s；Playwright E2E 258 passed，Chromium/WebKit 各 129，原生 114261.212ms，命令 116.54s。
实际 retry/skip/flaky/unexpected 均为 0，配置重试为 0；三树均 exit 0，源码前后字节稳定。仅 backend
pytest 使用原专用 PG 15.19 并核身份，Vitest 不使用 PG，E2E 使用 Fake API。上述是既有实现的回归
验证，不表示 B2 新表、迁移或数据库写入验证通过，也不替代独立 Review。
