# CP-05 回答推荐可读性与复制反馈（A26）

## 1. 范围

落实三端共享页面的窄屏/大字号、键盘和触控要求，仅修改AnswerRecommendations组件、该组件测试、answerRecommendations语言键及新增专用默认浏览器测试/测试夹具。不更改问题识别或推荐语算法、LiveKit接线、媒体状态、API/store/auth/platform、依赖、其他页面或既有E2E。浏览器夹具只在e2e目录，挂载真实组件，允许明确标注的useVoiceAssistant/clipboard桩；不得新增生产测试开关、真实房间或Provider调用。

当前代码对推荐正文使用truncate；复制反馈只保存按钮index，异步成功和1500ms定时清空没有来源归属。这些代码事实不等于已经完成真实设备复现。

## 2. 行为

推荐英文正文完整换行可读，不用ellipsis、缩小字号、删除内容、横向hidden/clip掩盖溢出。320x568、667x320、640x480、960x720，根字号100%/200%下，卡片/正文/复制提示可读、内容框无横向溢出、普通纵向滚动可达；按钮至少44x44 CSSpx，Tab/Enter/Space与可见焦点可用。复制完整原始推荐字符串，不带编号/提示文案；仅明确点击/键盘激活触发clipboard.writeText。

复制成功反馈只属于当前可见问题和该次用户操作：换题（含不同segment id的同文问题）、问题被撤回/改为非问题、thinking/speaking等待或卸载后，旧Promise成功/失败及旧定时回调不能影响新内容。相同问题的多次复制以最新明确点击的反馈为准；旧成功/失败或旧1500ms回调不得覆盖/清除更新反馈。新问题/恢复显示后显式复制仍正常，正常父重渲染不误清理健康反馈。保持1500ms反馈时长，失败不显示成功，不自动重试、不新增媒体/API写入；已调用的系统clipboard写入不能撤销，不承诺操作系统剪贴板异步完成顺序。

## 3. 验收

单测覆盖完整字符串复制、拒绝、延迟成功/失败、换题/相同文不同id、等待切换、卸载、重叠复制/旧计时器及再次成功；旧回调在清理前捕获并实际执行，不能用optional空调用造绿。按风险检查commit至passive清理间隙。已有算法与原单测断言保留，文本经answerRecommendations i18n键。

默认Chromium/WebKit测试挂载真实组件，验证几何、全文可见、44px、Tab/键盘、复制内容和无隐式副作用。使用真实文字Range/内容框和关键截图；夹具桩清晰，不把假LiveKit当真实媒体。每次Playwright独立output路径。既有606产品、18构建脚本及82默认E2E保留不skip、不弱化；完整七门禁、独立评审与隔离集成。
