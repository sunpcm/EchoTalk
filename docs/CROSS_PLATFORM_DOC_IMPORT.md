# CP-05 DocTalk本地文件导入可靠性（A24）

## 1. 范围

基于A23本地隔离集成，只允许DocUploadCard.tsx、其test.tsx、必要i18n/zh-CN.ts及新增e2e/doc-import.spec.ts。不改DocChatSetup/PromptBuilder/App/store/API/auth/platform/依赖/Fake API/已有E2E；现有组件测试可以按行为契约适配读取夹具，但不得删用例/弱化断言。目标来自TODO CP-05文件导入：取消不丢草稿，读取失败/空文件/编码/超限有提示。本增量仅本地Web能力准备，不代表原生文件选择器或真机验收。

## 2. 输入与失败

保留当前.txt/.md/.markdown（大小写不敏感）选择和相同文件再选、粘贴/编辑功能。不依赖accept或MIME保证格式：只接受这些文件扩展名。确定支持UTF-8（含BOM），无效UTF-8及不支持编码必须明确安全提示，不能静默替换为乱码覆盖草稿。保持50,000个JavaScript字符串长度单位的既有限制，不改变父组件或后端含义。解码后长度0或超过上限失败，不用trim悄悄改变内容。有效文本原样导入（UTF-8 BOM可去除），不自动提交/创建/Token/媒体或上传服务。

所有失败（不支持扩展名、读错误、解码错误、空内容、超限）保留当前草稿并显示明确本地化安全错误；不回显底层异常、文件路径或内容。读取失败后能再次选择合法文件，同一文件可再选。文件可先用保守200,003字节上限拒绝明显超大输入，来源为50,000长度单位×最多4UTF-8字节+3BOM，不拒绝任何既有长度限制内合法UTF-8；避免无界读取明显超限文件，不改变粘贴上限警告行为。

## 3. 读取归属与释放

每次选择仅最新仍有效读取能调用onChange或更新错误/读取状态。新选择、打开新选择器并取消、空files/cancel事件、用户手工编辑、已提交父value实质变化、卸载/StrictMode清理均应使旧读取失效；迟到load/error/abort无效，不能覆盖新文件/新草稿或清掉新错误。尽可能中止自有旧读取并清理回调/监听，但不能只依赖abort成功而无归属检查。普通未改value的父重渲染不能误取消健康读取。取消选择保留草稿，不产生新失败或外部写。处理启动/abort/read回调可能同步触发的边界，异常不逃出事件处理。

## 4. 验收

补产品回归：有效TXT/Markdown/BOM、扩展名与UTF-8拒绝、读取错误/空/超限保留草稿、同文件重选、取消；可控异步读取覆盖旧load/error/abort晚到、新选择和手工/父value变化、卸载与健康重渲染，错误后新操作可进。保留所有588产品和60默认E2E。新增默认Chromium/WebKit文件选择fixture（setInputFiles），实际观察草稿/安全错误/再次导入与零隐式API写；不伪装OS取消或真实文件选择器验收。截图testInfo.outputPath，每次output独立。完整七门禁/独立审查/变异/隔离集成，不安装/扩权限/真实服务/数据库/Xcode/设备/签名/push/deploy。
